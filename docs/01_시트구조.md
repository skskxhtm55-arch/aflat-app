# 01. 스프레드시트 구조 (1차)

- 시트와 첫 줄(열 이름)은 시트 메뉴 **에이플랫 관리 → 설치·테스트 도구 → ① 시트 구조 만들기/점검**이 자동으로 만듭니다.
- **열 이름은 바꾸지 마세요.** 열 순서는 바꿔도 됩니다(코드는 열 이름으로 값을 찾습니다).
- 휴대폰 번호, 수강생 번호처럼 맨 앞 0이 중요한 열은 "글자" 서식으로 맞춰 둡니다.
- 여러 값을 한 칸에 넣을 때는 **세미콜론(;)** 으로 구분합니다. 예: `피아노;보컬`
- 기능정의서 7-2와 다른 점은 맨 아래 "기능정의서와 달라진 점"에 정리했습니다.

## 회원 — 원장이 직접 수정할 수 있음
| 열 | 내용 | 예시 | 비고 |
|---|---|---|---|
| 회원ID | 자동 부여 | M0001 | 앱으로 등록하면 자동. 시트에 직접 추가할 때는 겹치지 않게 |
| 이름 | 회원 이름 | 조항빈 | **밑줄(_) 금지** (캘린더 제목 규칙) |
| 로그인ID | 휴대폰 번호, 숫자만 | 01012345678 | 같은 번호를 쓰는 회원은 **계정 1개로 자동 연결** (형제·학부모) |
| 연락처 | 알림톡 받을 번호 | 01012345678 | 비우면 로그인ID로 발송 |
| 역할 | 원장 / 강사 / 수강생 | 수강생 | 원장 역할이 있는 계정만 앱의 "관리" 메뉴를 봄 |
| 수강생번호 | 캘린더 식별자 | PAM004 | 기존 번호 그대로. 영문·숫자·하이픈. 강사도 예약하려면 입력 |
| 담당강사 | (2차용) | | |
| 수강클래스 | (2차용) | | |
| 등록악기 | 예약 가능한 악기 | 피아노;보컬 | **룸 시트 허용악기와 글자가 똑같아야** 배정됨 |
| 상태 | 활성 / 휴원 / 종료 | 활성 | 휴원: 로그인·조회만 가능, 예약 불가 / 종료: 로그인 불가. 빈칸은 활성으로 봄 |
| 가입일 | 등록일 | 2026-11-19 | |
| 메모 | 자유 메모 | | |

## 계정 — ⚠ 직접 수정 금지 (시트 보호: 경고)
| 열 | 내용 |
|---|---|
| 로그인ID | 휴대폰 번호 (계정 1개 = 번호 1개) |
| 비밀번호해시 | PBKDF2-SHA256 결과. 원문은 어디에도 저장하지 않음 |
| 솔트 | 계정마다 다른 무작위 값 |
| 반복횟수 | 해시 반복 횟수 (나중에 보안 강화 시 계정별로 높일 수 있음) |
| 임시비밀번호여부 | Y면 다음 로그인 때 비밀번호 변경 강제 |
| 임시비밀번호만료일 | 발급 후 7일 |
| 로그인실패횟수 | 5회가 되면 10분 잠금 후 0으로 초기화 |
| 잠금해제시각 | 이 시각까지 로그인 불가 |
| 최근로그인일시 | |
| 발급일시 | 계정을 처음 만든 시각 |

> 비밀번호 초기화·잠금 해제는 앱 **관리** 화면 또는 시트 메뉴 **에이플랫 관리 → 임시 비밀번호 발급 / 로그인 잠금 해제**로만 합니다.

## 세션 — ⚠ 직접 수정 금지
| 열 | 내용 |
|---|---|
| 토큰해시 | 로그인 토큰의 SHA-256 (토큰 원문은 기기에만 있음) |
| 로그인ID | |
| 발급일시 / 만료일시 | 90일 유지 |
| 기기정보 | 브라우저 정보 일부 |

> 한 줄을 지우면 그 기기는 로그아웃됩니다. 만료된 줄은 "매일 자동 정리"로 지워집니다.

## 룸 — 원장이 직접 수정할 수 있음 (기능 I-3)
| 열 | 내용 | 예시 |
|---|---|---|
| 룸ID | 고유 이름 | R1 |
| 이름 | 캘린더 제목에 들어가는 방 이름 | Eb |
| 표시순서 | 시간표 왼쪽부터 순서 | 1 |
| 캘린더ID | 그 룸의 구글 캘린더 ID | xxxx@group.calendar.google.com |
| 허용악기 | 이 룸에 배정 가능한 악기 | 피아노;보컬;기타 |
| 배정우선순위 | 숫자가 작을수록 먼저 배정 | 1 |
| 사용가능여부 | Y / N | N이면 시간표에서 숨기고 배정하지 않음 (1일 한도 집계에는 포함) |

## 운영설정 — 원장이 직접 수정할 수 있음 (기능 I-3)
| 항목 | 기본값 | 의미 |
|---|---|---|
| 운영시작 | 08:00 | 이 시각 이후에 시작하는 예약만 가능 |
| 운영종료 | 24:00 | 이 시각까지 끝나는 예약만 가능 (자정은 24:00) |
| 예약가능일수 | 7 | 오늘 포함 7일 (오늘~6일 후). 시간표 조회 범위도 같음 |
| 1일최대분 | 120 | 1인 1일 합계. "(연습)" 일정만, 수강생 번호 정확 일치로 집계 |
| 이용시간선택지 | 30;60;90;120 | 예약 화면 버튼 |
| 최소분할분 | 30 | 2개 룸 분할 시 각 구간 최소 길이 |
| 분할단위 | 15 | 분할 지점 간격(시작 시각 기준) |
| 분할가능최소이용분 | 60 | 이 값 이상일 때만 분할 시도 |
| 지난시각허용분 | 30 | 오늘 예약에서 현재 시각보다 이 분만큼 이전에 시작하는 시각까지 허용 (0 = 지난 시각 불가). 예: 15:20이면 14:50 시작까지 |
| 시간표캐시초 | 60 | 시간표를 잠시 기억하는 시간. 0이면 매번 캘린더 조회(느려짐) |

> 고친 뒤 **에이플랫 관리 → 설정 즉시 반영**을 누르세요. 누르지 않으면 최대 5분 뒤 반영됩니다.
> 값이 잘못되면 앱에 "운영설정 값이 올바르지 않습니다: (항목)" 안내가 뜹니다.

## 예약로그 — 기록용 (예약 판단에는 쓰지 않음)
로그ID, 로그인ID, 회원ID, 수강생번호, 악기, 룸(분할 시 `Eb [1/2]` 처럼 2줄), 날짜, 시작, 종료, 결과(성공/실패), 실패사유, 생성일시, 리마인드발송일시(H-1, 2차용)

## 재설정요청 — 비밀번호 재설정 요청 기록
요청ID, 입력ID, 해당회원, 요청일시, 상태(접수/처리완료/무시), 처리일시, 비고(계정 없음 등)
- 임시 비밀번호를 발급하면 그 번호의 '접수' 요청이 자동으로 '처리완료'가 됩니다.

## 알림로그 — 알림톡 발송 기록
로그ID, 유형, 대상, 발송일시, 결과(성공 / 실패 코드 / 미발송(off 모드) 등)

## 구글 캘린더 (룸 점유의 원본)
- 룸별 캘린더 4개. 앱은 일정을 **읽고(시간표·내 예약·1일 한도)**, 수강생 예약을 **등록**만 합니다.
- 제목 규칙(기능정의서 C-0-1)
  - 연습: `(연습)방이름_수강생명_악기_수강생번호` → `(연습)Bb_조항빈_피아노_PAM004`
  - 분할: 위 제목 + ` [1/2]` / ` [2/2]`
  - 레슨: `(레슨)방이름_수강생명_악기_수강생번호` (2차 C-5에서 사용)
- 예약 취소: 원장님이 캘린더에서 일정을 지우면 끝입니다. 시간표·내 예약·1일 한도에 자동 반영됩니다(시간표는 최대 60초 늦게).

## 기능정의서와 달라진 점 (구현 중 결정·가정)
| 항목 | 기능정의서 | 구현 | 이유 |
|---|---|---|---|
| 계정 시트 기준 열 | 회원ID | 로그인ID | 형제가 번호 1개를 함께 쓰는 경우 계정 1개에 여러 회원 연결 (결정 1-1) |
| 회원 시트 | 연락처(=로그인ID) | 로그인ID·연락처 분리 | 로그인 번호와 알림톡 번호가 다를 수 있음. 연락처를 비우면 로그인ID 사용 |
| 세션 시트 | 토큰 | 토큰해시 | 시트를 본 사람이 로그인을 가로채지 못하게 |
| 계정 시트 | - | 반복횟수, 발급일시 추가 | 해시 강도 조정, 이력 |
| 운영설정 | - | 분할가능최소이용분, 시간표캐시초, 지난시각허용분 추가 | 현행 코드의 60분 기준을 시트로 옮김, 캐시 시간 조정 |
| 재설정요청 시트 | 없음 | 신설 | A-5 요청 이력·처리 상태 관리 |
