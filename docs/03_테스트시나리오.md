# 03. 테스트 시나리오 (테스트 환경)

`02_설치배포가이드.md` 6단계 **② 테스트 환경 만들기**가 만든 데이터를 기준으로 합니다.
날짜는 실행한 날 기준: **D+1 = 내일, D+2 = 모레, D+3 = 글피**

| 11-3 | 변경하기 | "예약 변경" 화면, 악기·날짜·시각·이용시간이 기존 값으로 채워짐, "변경 전: …" 안내 |
| 11-4 | 시각만 1시간 뒤로 → 이대로 변경하기 | "예약이 변경되었어요!" / 캘린더: 새 일정 생김 + 기존 일정 사라짐 / 예약로그 '변경' + 비고 "변경 전" / (test 모드면) 알림톡 새 내역 |
| 11-5 | 같은 날 하루 한도 꽉 찬 상태(120분)에서 그 예약 시간을 옮기기 | 가능 (기존 예약 시간은 빼고 계산) |
| 11-6 | 다 찬 시간(예: 단체 수업 시간)으로 변경 | "변경하지 못했어요(기존 예약은 그대로예요): …" / 캘린더 기존 일정 그대로 |
| 11-7 | 분할 예약([1/2]·[2/2]) 변경 또는 취소 | 두 일정이 함께 바뀜/지워짐 |
| 11-8 | 예약 취소 → 확인 | "예약을 취소했어요." / 캘린더 일정 삭제 / 예약로그 '취소' / 알림톡 없음 |
| 11-9 | 두 기기로 같은 예약 화면을 연 뒤, 한쪽에서 취소 → 다른 쪽에서 변경·취소 | "이미 취소되었거나 바뀐 예약이에요…" |
| 11-10 | 진행 중인 예약(시작했지만 안 끝남) | 변경·취소 가능. 끝난 예약은 › 없음 |
| 11-11 | 운영설정 변경취소마감분 = 60 → 설정 즉시 반영 → 끝나기 60분 이내 예약 | 누를 수 없음 → 확인 후 0으로 |
| 11-12 | (드문 경우) 예약해 둔 뒤 회원 시트에서 휴원으로 바뀐 수강생 | 남은 예약 취소는 가능, 변경은 "취소만 가능해요" |
