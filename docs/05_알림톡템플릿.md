# 05. 알림톡 템플릿

## H-8 연습실 예약 확정 — 현행 템플릿 재사용 (신규 신청 불필요)
- 스크립트 속성 `TEMPLATE_BOOKING_SUCCESS` = 현행 Code.gs 의 `TEMPLATE_SUCCESS` 값
- 변수: `#{이름}`, `#{날짜}`, `#{예약내역}` — 현행과 같은 형식으로 보냅니다
  - `#{날짜}` 예: `2026년 11월 20일 (금)`
  - `#{예약내역}` 예: `18:00~19:00 Eb` / 분할 시 `18:00~19:00 Eb, 19:00~20:00 Bb`
- 현행 예약 실패 템플릿은 앱에서 쓰지 않습니다(화면에 바로 안내).

## H-6 비밀번호 재설정 요청 (원장님 수신) — 신규 신청 필요
솔라피 → 카카오 알림톡 → 템플릿 등록. 아래는 신청용 초안입니다(문구는 자유롭게 수정 가능, **변수 이름은 그대로**).

- 템플릿 이름: 비밀번호 재설정 요청 알림
- 카테고리(예): 회원 > 비밀번호 / 또는 기타 업무 알림
- 본문
```
[에이플랫 앱] 비밀번호 재설정 요청

#{이름}님(아이디 #{아이디})이 비밀번호 재설정을 요청했습니다.
요청 시각: #{요청일시}

본인 확인 후 앱 [관리 > 재설정 요청]에서 임시 비밀번호를 발급해 주세요.
```
- 변수 예시: `#{이름}` = `박형·박동생`, `#{아이디}` = `010-1234-5678`, `#{요청일시}` = `2026-11-19 15:30`
- 승인되면 템플릿 ID를 스크립트 속성 `TEMPLATE_RESET_REQUEST` 에 입력
- 승인 전에도 요청은 **재설정요청 시트·앱 관리 화면**에 쌓이므로 업무는 가능합니다(알림로그에 "템플릿 ID 미설정"으로 기록).

## 발송 모드 (스크립트 속성 `ALIMTALK_MODE`)
| 값 | 동작 |
|---|---|
| off (기본) | 보내지 않고 알림로그에 내용만 기록 |
| test | 모든 알림톡을 `ALIMTALK_TEST_PHONE` 한 번호로만 발송 |
| live | 실제 대상에게 발송 (실운영) |
